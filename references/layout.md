# 模板结构与 CAD 材料表识别规则

本文件供需要调整解析规则或更换设计院图框时查阅。首次使用只要 `inspect` 结果正确，
无需改动这里的任何参数。

## 1. 两套模板与列定义

| 模板（`--template`） | 文件 | 工作表 | 明细容量 | 定位 |
|---|---|---|---|---|
| `summary`（默认） | `材料汇总模板-加强比对版.xls` | 9 张 | 第 4～118 行（115 行） | 空白加强比对版，新项目生产用；含 `2-汇总`、新旧打印版、`5-变更估价`、`@变更单EXCEL模板`、`调拨价` |
| `sample` | `材料平差模板.xls` | 10 张 | 第 4～43 行（40 行） | IC24H201 成品文件，另含 `广联达导入`、`206-变更单打印`；用于复现与逐格验收 |

两份模板的 `1-初步比对` 表头与列含义完全一致，第 3 行是空行（A3=0），
第 1～2 行是两层表头。模板容量由 O 列比对公式的最后一行自动探测
（成品 43 / 加强版 118），脚本中不写死行数。

| 列 | 含义 | 本技能是否写入 |
|---|---|---|
| A | 编号 1..N | 是 |
| B | 标记（分组标题行写 2，「不用入物资系统材料：」除外） | 是 |
| C | 竣工图-物料描述 | 是 |
| D | 竣工图-单位 | 是 |
| E | 竣工图-数量 | 是 |
| F/G/H | 材料平差：领量 / 退量 / 平差 | 否，保持模板原值或公式 |
| I | 标记（同 B） | 是 |
| J | 施工图-物料描述 | 是 |
| K | 施工图-单位 | 是 |
| L | 施工图-数量 | 是 |
| M/N | 领量 / 退量（占位） | 否 |
| O | 异同，公式 `=IF(C4=J4,"相同","")` | 否，保留公式自动重算 |

分组标题行（无单位、无数量、描述以「：」结尾）示例：
`配套中压地下材料：`、`不用入物资系统材料：`、`中压地上部分：`、`配套地上部分：`。

写入前只清空 `A4:E{末行}` 与 `I4:L{末行}`（末行 = max(写入行数, 模板容量)）；
输出行数超过模板容量时，用 `Range("O{容量}:O{last}").FillDown()` 把 O 列公式补到新增行。

### `2-汇总` 同步映射

`2-汇总` 与 `1-初步比对` 之间**没有跨表公式**，C/D/E/I 是人工「变更复制区」。
本技能按成品文件的实际填法自动同步，只动这四列：

| `2-汇总` 列 | 含义 | 来源 / 处理 |
|---|---|---|
| A | 编号 | 沿用模板预置编号，不写（打印版 VLOOKUP 依赖完整编号列） |
| B | 标记 | 不动 |
| C / D / E | 物料描述 / 单位 / 竣工数量 | 取 `1-初步比对` 的 C / D / E |
| F / G | 领量 / 退量 | 不动，由施工单位后续填报 |
| I | 施工图数量 | 取 `1-初步比对` 的 L（竣工独有项留空） |
| H / J / K / L / M / N | 平差 / 变量 / 增加材料 / 减少材料 | 模板公式，自动重算；行数超容量时 FillDown 扩展 |

下游 `4-汇总打印版 (新版)` 用 `VLOOKUP($A5,'2-汇总'!$A:$N,...)` 取数，
`5-变更估价` 同样引用 `2-汇总`，因此四列填入后整本汇总表即联动。
若模板的 C/D/E/I 首行是公式（而非空白常量），脚本跳过同步以免破坏模板。
`--no-fill-summary` 可完全关闭这一步。

## 2. CAD 图纸里的材料表长什么样

样例（IC24H201 南昌县向塘博乐美幼儿园）中，一份 DWG 会同时出现多张表：

| 图纸 | 表 | 阶段标注 | 有效行 |
|---|---|---|---|
| 竣工图 | `燃气管道布置图、材料表`（图签写「竣工图」） | 竣工图 | 40（分上下两段续表：29 + 11） |
| 竣工图 | 3 页 `工艺设备材料表` | 施工图 | 29 + 6 + 17 |
| 施工图 | 3 页 `工艺设备材料表` | 施工图 | 29 + 6 + 17 |

因此**不能简单地把 DWG 里第一张表当作该图的材料表**：竣工图 DWG 里
「竣工图」阶段的表才是竣工材料表，其余三页是随图附带的施工图版本。
施工图第 3 页是户内材料（DN25 波纹软管、超声波表、探测器等），
成品模板中没有对应行，匹配后被列为「施工图多出」，不写入表格。

材料表不是 AutoCAD TABLE 对象，而是由 `LINE` 网格加独立 `TEXT/MTEXT` 文字构成。
表头一行文字（含居中用的空格）：

```
序号 |  物      料      描      述 | 单位 | 数量 | 标 准 号(现行) | 备  注
```

## 3. 解析算法与可调参数（都在 `scripts/dwg_tables.py`）

1. **表头检测**：同一 y（±320）且 x 在右方 22000 图形单位内，出现
   `序号 / 物料描述 / 单位 / 数量` 四个表头文字即认定一张表；
   每个表头列取距离本「序号」最近的匹配，避免并排多表时错配列锚点。
   表头文字归一化由 `norm_header()` 完成（去空格与全角空格、括号）。
2. **比例自适应** `_table_scale()`：`scale = (单位锚点 − 序号锚点) / 10126`。
   IC24H201 / NC25D007 图框 `scale=1.00`；ID24E107 是 1:2 缩放图框
   （锚点间距 10126 → 5063），`scale=0.50`。`_column_bounds()`、
   `_seq_entities()`、`parse_table()` 里所有固定偏移与 y 容差都乘以 scale，
   `inspect` 会打印每张表的「比例」。这是不同设计院/不同出图比例能共用一套
   参数的关键，**排查解析问题先看这个值**。
3. **阶段判定** `detect_stage()`：在表头 y ±12000×scale、表格 x 范围内找
   图签文字「竣工图」/「施工图」，取距离表头最近者。左右并排的多页常只有一页
   有图签，未标注页会继承 y 接近（<2.5 倍表宽）、x 相邻（<4 倍表宽）的
   已标注页，`inspect` 显示为「竣工图(继承)」。
4. **列边界** `_column_bounds()`：表头居中文字的插入点 x 明显右于同列数据，
   所以不用锚点中点，而用固定偏移 ×scale（下表为 scale=1 时的图形单位）：

   | 列 | 下界 | 上界 |
   |---|---|---|
   | 序号 | 序号锚点 − 1500 | 序号锚点 + 600 |
   | 物料描述 | 序号锚点 + 600 | 单位锚点 − 1500 |
   | 单位 | 单位锚点 − 1500 | 数量锚点 − 600 |
   | 数量 | 数量锚点 − 600 | 数量锚点 + 700 |
   | 标准号 | 数量锚点 + 700 | 备注锚点 − 1500 |
   | 备注 | 备注锚点 − 1500 | 表格右边界 |

   标准号/备注表头缺失时，用 `数量锚点 + 2500×scale`、`+ 2800×scale` 推算。
   **换图框时优先调这里**：先 `inspect` 看「比例」和有效行数，再用
   `extract --out rows.json` 逐行核对描述/单位/数量是否串列。
5. **页序** `detect_tables()`：表头按 y 降序、同排 x 升序编号；
   上下并排时上页在前，左右并排时左页在前。`--tables 2,1` 按给定顺序拼接。
6. **行锚点** `_seq_entities()`：在序号列、表头 y ±42000×scale 内取所有
   1～3 位数字。`_split_segments()` 自动判断表格是自上而下还是自下而上排布，
   并在序号从 1 重新开始时切段（续表 / 新页），段边界用相邻段 y 中点切开。
7. **视觉行** `parse_table()`：文字按 y 聚类（容差 300×scale）成视觉行，
   每行按 x 归列；带序号的视觉行是记录锚点，无序号的相邻文字行
   归入 y 最近的锚点。这样既能把拆成两行的物料描述（如
   `标准楼栋调压箱_..._不锈钢箱体` + `（出口设定压力：2.5KPa）`）
   用 `\n` 合并，又不会把相邻行串进来。
8. **噪声过滤**：`SIGN_WORDS` 过滤图签文字（编 制/校 核/审 核/日 期 等），
   `_valid_unit()` 要求单位不含空格与数字且长度 ≤3，
   描述列排除纯数字，表头行整行跳过。

## 4. 匹配规则（`scripts/import_materials.py`）

- 以竣工行顺序为基准，在施工图**同分组**内按 `norm_desc()` 归一化描述精确匹配，
  命中后标记为已消耗（处理 `螺栓_M20*100` 这类在不同分组重复出现的物料）。
- 未命中的竣工行：J 写竣工描述、K 写竣工单位、L 留空——与成品模板一致。
- `--match-mode global` 忽略分组，`hybrid` 先同组再全局；默认 `group` 能复现模板。
- 分组由 `assign_groups()` 标注，跨页表格继承上一页最后的分组标题，
  因此施工图第 2 页的 6 项会自动归入「配套地上部分：」。

### 多实例验收基准（v1.2.0）

| 指标 | 期望值 |
|---|---|
| IC24H201 竣工 / 施工提取 | 40 行 36 项 / 52 行 47 项；匹配 31、竣工独有 5、施工多余 16 |
| IC24H201 `--template sample --no-fill-summary` | 与成品 A3:O43 共 410 格 **0 差异**；10 张表、10 个定义名、O 列公式保留 |
| NC25D007 竣工提取 | 73 行（两页 41 + 32，其中一页阶段为「继承」）；施工图侧自动补入 59 项 |
| NC25D007 与成品 | 描述与行序提取正确；成品另含人工插入的 2 项施工图独有项及另一版次数量，逐格差异约 250 处，属人工整理差异 |
| ID24E107 图框比例 | **0.50**（1:2 缩放）；竣工 32 行、施工 32 行 |
| ID24E107 `--row-base merged` | 41 行，与成品 A3:O44 **0 差异** |
| 默认 `summary` 模板（三实例） | 9 张表；`1-初步比对` → `2-汇总` 的 C/D/E/I 四列同步 0 差异 |

## 5. 已知限制

- 依赖 Windows COM（CAD 与 Excel）；纯 Linux/macOS 环境需先把 DWG 转 DXF
  并改用其它 Excel 写入方案。
- 默认加强版模板容量 115 行（`2-汇总` 172 行）；超容量时 `1-初步比对` 的 O 列与
  `2-汇总` 的 H/J/K/L/M/N 公式会自动 FillDown，但 `1-初步比对` 的 F/G/H、M/N
  （领退量）不会延伸；`4-汇总打印版 (新版)` 只有约 65 行、`5-变更估价` 约 38 行，
  材料极多时需人工扩展这两张表并复核联动。
- 表格若使用真正的 AutoCAD TABLE 对象、属性块或 OLE 表格，文字枚举取不到内容，
  需先在 CAD 里炸开（EXPLODE）成 TEXT。
- 物料描述变更（施工/竣工名称不同）会按「竣工独有 + 施工多余」列出，
  需要人工判断是否为同一物料改名，脚本不做模糊匹配。
- 成品文件常含人工插入/合并的行、或取自另一版次的数量（NC25D007 即如此）。
  技能按图纸原始数据生成，差异项在核对报告中按分组列出；不要用成品差异
  反推解析参数，交付前需人工复核后再用于结算。
